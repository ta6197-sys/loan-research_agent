# 상신브레이크 로컬 PoC 후속 마무리

2026-10-21. 대상은 상신브레이크·공개 기준일 2026-10-20의 보관 공개 자료다. 일반 기업/새 기준일 자동 수집과 금융 확인 완료로 확대하지 않는다.

## 후속 구현

- 사업·판매·지역·거래 구조의 7개 인용을 정확한 원문 행/문단·범위·원문 바이트와 연결한다. 연결 지역 표를 차주 단독 구성으로 바꾸지 않는다. 일곱 항목 최소 확인표는 부분 확인과 내부 정보 미제공을 표시하고, 질문에는 관찰 근거와 답변 후 확인할 내용을 제공한다.
- PDF/XLSX/CSV/TXT의 공개·합성 첨부를 로컬에서 제한해 읽는다. PDF의 암호/텍스트 없는 페이지, XLSX의 숨김/저장 수식 캐시/누락 캐시/외부 링크를 구분한다. 수식·외부 링크는 실행하지 않고 OCR·암호 해제를 하지 않는다. 첨부의 읽기 성공과 금융 검증을 구분한다.
- 여러 파일은 한 첨부 묶음과 한 후속 입력으로 접수한다. 재전송은 같은 입력/실행을 사용하며 일부 원문 저장 실패 시 완료 전 실행하지 않는다. 원문과 읽기 기록의 해시를 검사한다. 첨부의 지시·숫자는 공시 검증 수치를 바꾸지 못한다. 게시본 조회에서도 연결 첨부 원문 해시를 재검사한다.
- 조사 누적 파일 10개·파일당 20MiB·총 100MiB, PDF 200쪽·표 50,000셀을 제한한다. 읽기 프로세스에 CPU/메모리/실행시간 한도를 둔다. 파일 준비/읽기는 조사 실행 전 접수 시간이며 조사 실행 예산과 구분한다. 악성코드 전수 검사·OS 네트워크 격리·완전한 DLP는 제공하지 않는다.
- 계획 변경은 목적과 우선 항목만 지원한다. 나머지 일곱 항목도 조사하며 새 기준/실행으로 대기한다. 현재 실행과 이전 판/사용량은 수정하지 않는다. 새 기준은 보관 공시로 다시 조사하고 이전 기준의 답변을 자동 혼합하지 않는다. 이전 답변·첨부는 당시 게시본에서 열람한다. 회사/기준일 변경과 임의 도구/검색 계획 편집은 미지원이다.
- 보관함 이동은 현재/대기 작업을 중단하고 기본 목록·보고서·근거·이력 조회에서 숨긴다. DB·원문·게시본·사용량을 삭제하지 않는다. 서버 재시작 후에도 유지되며 복원한 조사는 명시 재개 전 실행하지 않는다. 실제 삭제·보관기간 자동화는 구현하지 않는다.

## 완료 판정과 검증 기록

사용자 요청으로 OpenAI 전환 준비 전에 현재 상태를 중간 저장한다. 전체 구현 완료 판정은 아직 하지 않는다.

- 309개 회귀·원문 재대조·오류 주입 8종·2개 HTTP 서버 재조회·보호 638파일 변경/삭제 0: `validation_stage04_completion/20261021T125934Z-e6b3cbca/verification.json`. 이후 계획 재전송/보관 접근/출력 배치를 보강했으므로 이 지문은 현재 모든 소스의 최종 완료 증거가 아니다.
- 로컬 고정/그래프 각 3회 비교 모두 정상·매회 모델 1회·114확인/16보류: `evaluation_stage09/20261021T125934Z-1e31d4b9/result.json`. 고정 시점 이후 수정은 별도 시험 대상이며 기존 평가 결과를 덮어쓰지 않는다.
- 실제 HTTP 첨부 2개→한 입력→2판, 중단 계획→보관→재시작→복원/명시 재개→3판, 기존 판/수치/예산 보존: `validation_stage08/final-20261021T130504Z-e0c18ae1/result.json`. 서버 3개·로컬 모델 3회(후속 첫 출력의 미확인 누락 거부 후 재시도 포함)·외부 요청 0회.
- 화면에서 보관/복원·중단 계획 저장·사업 B6 연결 근거·모바일 배치 확인. 증빙은 Git 제외 `output/pdf/finance-final-*.png`에 보존한다.
- 제목/인용 페이지 분리를 보완한 출력 1.3을 별도 복사본에서 생성하고 HTTP 서버 2개로 같은 화면/PDF/ZIP을 확인했다: `validation_stage08/20261021T130748Z-275f3f24/result.json`. 18쪽 PDF의 **최신 배치 시각 확인은 아직 남아 있다**. 이전 출력의 시각 검토를 새 출력의 확인으로 바꾸지 않는다.
- 작업 초반 원본 보호 1,357파일 변경/삭제 0을 확인했다.

남은 검증은 마지막 수정 이후 전체 통합 지문 재생성·최신 PDF 시각 확인과 OpenAI 연결 후 별도 평가다. 로컬 모델 비교와 외부 모델 평가를 같은 결과로 섞지 않는다.

커밋 직전 마지막 소스로 전체 회귀 309개를 다시 실행해 모두 통과했다. 이 재실행은 전체 통합 지문 재생성과 최신 PDF 시각 확인을 대신하지 않는다.

## OpenAI 전환 준비

사용자가 OpenAI API 사용을 선택했다. 기존 `.env`는 보존하고 Git 제외 `.env.openai.local`에 빈 `OPENAI_API_KEY=`만 준비했다(파일 권한 600). 키는 채팅/커밋/배포에 넣지 않는다. 표준 변수명은 [공식 OpenAI Quickstart](https://developers.openai.com/api/docs/quickstart)를 따른다. 현재 금융 경로는 여전히 로컬 모델이며 이 파일을 자동으로 읽지 않는다. 모델과 외부 전송 자료 범위를 확인한 뒤 전용 연결·예산/오류/출력 검증을 적용해야 한다. 새 OpenAI 호출은 아직 0회다.
