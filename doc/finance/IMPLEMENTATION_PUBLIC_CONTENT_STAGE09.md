## 바뀐 동작

- `public_content.py`가 별도 당반기 현금흐름 조정3행, 외화환산이익/조정2행, 당기 별도 감사1행, 소송 설명1행, 후속 보증6행을 원문 인용으로 연결한다. 값·손실·회수 원인을 추정하지 않는다.
- 다른 범위/시기·다중 후보·빠진 머리글/위조 위치는 확인 인용으로 쓰지 않는다. 원시 바이트·표/행·열/머리글·기간 표제·원문 해시를 다시 검사한다. 현재 확인한13행을 전체 공시 검토나 금융 전문가 검토로 표시하지 않는다.
- 화면에 주석·감사·후속 공시와 해석 한계를 표시하고 P1~P13으로 근거 패널을 연다. 보증 공시는 별도/연결 재무 수치와 구분한다. 같은 게시본의 PDF·Markdown ZIP에도 인용과 위치/근거를 포함한다. 기존 후보 검색 발췌가 빈 문자열로 보이던 `snippet` 표시도 보완했다.
- 원문 파서는 UTF-8 바이트에 남아 있는 EUC-KR HTML 선언을 잘못 적용하지 않게 보완했다. 엄격한 UTF-8 검사는 유지하고 원문은 수정하지 않았다. 추출 버전1.8, 화면 투영/출력1.1로 구분하며 예전 검증/출력 파일을 덮어쓰지 않는다.
- 새 보고서의 한계 문구를 현재 복구·화면·출력 상태에 맞췄다. 이미 게시된 예전 판의 당시 문구는 그대로 보존한다.
