# 30392 공장·법인 식별 자료 제공 문의 초안

작성일: 2026-10-26. **미제출 초안**. 수신 후보: 공공데이터포털을 통한 한국산업단지공단 공장설립온라인지원시스템 담당 부서. 실제 제출에는 사용자 결정과 정확한 접수 경로 확인이 필요하다.

## 문의 제목

팩토리온 업종관리 자료의 공장-법인 식별 및 KSIC 개정 차수 확인 방법 문의

## 문의 본문

안녕하세요. 공개된 [한국산업단지공단 팩토리온 업종관리 2021-07-31 자료](https://www.data.go.kr/data/15088923/fileData.do)를 사용하여 제동장치 제조업(KSIC 제10차·제11차 30392) 공장과 DART 공시 법인을 구분해 조사하고 있습니다.

제공 파일에는 회사명, 시도·시군구, 대표업종, 업종코드, KSIC 차수는 있으나 공장등록번호·상세 공장 소재지·법인 연결 식별자가 없습니다. 동일 회사명만으로 공장과 공시 법인을 연결하지 않으려 합니다. 다음을 확인 부탁드립니다.

1. 공개 가능한 공장등록번호 또는 다른 공장 단위 고유 식별자와 상세 소재지를 포함하는 **최신 공식 자료나 조회 경로**가 있는지요?
2. 공장 단위 식별자와 법인등록번호 또는 사업자등록번호를 연결할 수 있는 **공식 확인 절차**가 있는지요? 번호 자체를 공개할 수 없다면, 특정 공장과 특정 DART 법인의 동일 여부를 공식적으로 확인받을 수 있는 방법을 알려주십시오.
3. 팩토리온 업종관리 파일의 제9·10차 코드와 최신 제11차 코드 사이에서 공장별 업종 변경 이력·기준일을 확인할 수 있는 자료가 있는지요?
4. 제공이 제한되는 항목이 있다면, 제공 가능한 대체 필드·집계 수준·신청 절차와 제한 사유를 알려주십시오.

조사 대상은 기존 공개 파일에서 대표 업종이 제10차 30392인 공장 39건과 [고양시 제11차 공장자료](https://www.data.go.kr/data/3080741/fileData.do)의 3건입니다. 제9차 30392 1건은 전기장치 업종이어서 대상에서 제외했습니다. 개인정보나 비공개 자료의 공개를 전제로 하지 않으며, 공개 가능한 공식 연결·확인 경로를 문의합니다.
