# 상신브레이크 비교집단 후보 조사

조사일: 2026-10-23. 아래 OpenDART 응답은 공식 API에 직접 조회한 탐색 결과다. 아직 조사 저장소의 원문·검증 배치와 결합하지 않았으므로 데이터셋 행이나 검증 완료 기업으로 취급하지 않는다.

## 산업 분류의 차이

OpenDART [기업개황 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002)의 `induty_code`를 2026-10-23 조회했다.

| 회사 | DART 고유번호 | DART 업종코드 | 2023~2025 사업보고서 | 2026 반기보고서 |
|---|---|---|---|---|
| 상신브레이크 | `00129642` | `303` | 있음 | 있음 |
| KB오토시스 | `00157539` | `303` | 있음 | 있음 |
| 새론오토모티브 | `00305668` | `303` | 있음 | 목록에서 확인되지 않음 |
| HL만도 | `01042775` | `303` | 미확인 | 미확인 |
| 산도브레이크 | `01897625` | `30392` | 미확인 | 미확인 |

`303`은 자동차 신품 부품 제조업의 넓은 범위다. `303`만 같은 회사를 제동장치 제조업 `30392`로 자동 승격해서는 안 된다. [새론오토모티브의 2026년 공시](https://kind.krx.co.kr/external/2026/03/13/000387/20260313001220/00591.htm)는 제11차 한국표준산업분류 `30392`를 명시하고 상신브레이크·KB오토시스를 비교 업체로 적지만, 이 문서만으로 두 비교 업체 각각의 법인별 업종 증명이 되지는 않는다. 각 회사의 자체 공시 또는 공식 분류 원문을 별도로 확보해야 한다.

## 실행 전 확인

1. 비교 기준을 OpenDART `303`으로 할지 제11차 KSIC `30392`로 할지 사용자 선택을 기다린다.
2. 선택된 범위의 각 회원 회사에 대해 법인 식별, 산업 분류, K-IFRS, 공개 시점의 원문 근거를 저장한다.
3. 기존 일반 기업 수집·검증·게시 절차를 실행하고, 통과한 기업·기간만 불변 스냅샷에 담는다. 수집된 API 숫자를 자동으로 검증 통과 처리하지 않는다.
4. 실제 표본이 통계 10개 기업·20개 관측, ML 30개 기업·150개 연간 관측 게이트에 못 미치면 결과를 보류한다.

선택된 기준과 무관하게 현재 저장소에서 게시된 검증 보고서가 있는 대상은 상신브레이크뿐이다. KB오토시스·새론오토모티브의 정기공시 존재는 확인했지만 수치 원문 검증·게시까지는 수행하지 않았다.
