# OpenDART 관측 `303` 계열 별도 비교집단

기준일: 2026-10-27. 이 집단은 기존 KSIC `30392` 세부 코호트와 별도로 유지한다.

## 후보와 근거

기존 [117곳 감사](COHORT_CANDIDATE_AUDIT_20261025.json)를 다시 사용했다. 2025 사업보고서와 2026 반기 XBRL에서 각각 단일 `StandardIndustryCode`가 추출되고, 두 값이 같으며 `303`으로 시작한 법인은 **87곳**이다. 코드 변경 1곳, `303` 범위 밖 12곳, 한쪽 XBRL 코드 미확인 17곳은 후보에서 보류했다. [후보 명세](BROAD_303_CANDIDATES_20261027.json)에 기업별 접수번호·관측 코드·제외 상태와 원본 감사 해시를 기록했다. 이 87곳은 **검증된 비교기업 수가 아니다**.

OpenDART의 [XBRL 원본 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019019)는 정기보고서의 원본 파일을 접수번호와 보고서 코드로 제공한다. [정기보고서 재무정보 안내](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS003)는 이 제공 범위가 상장법인 및 일부 비상장 법인임을 설명한다. 이 API에 자료가 있어도 업종 개정 차수, 계정 의미, 원문 금액 검증을 자동 승인하지 않는다.

## 이미 보관한 미게시 검증 실행의 분석 전용 재사용

사용자가 허용한 범위에서 기존 KB오토시스와 새론오토모티브 실행을 읽기 전용으로 재확인했다. 정정 관계를 반영한 미게시 분석 읽기 모델, 원문 위치, 숫자 검증, 실제 기간·결산월 및 독립 XBRL 계정·기간·금액 게이트가 모두 통과한 행만 사용했다. 각 보고기간의 원문에 `한국채택국제회계기준` 기재가 있는 위치와 XBRL 자체 업종 코드를 기록했다. 회사 전체 연결·별도 재무제표를 제동장치 사업부만의 실적으로 해석하지 않는다.

새론오토모티브의 2023년 XBRL 자체 코드는 `30392`이며 2025 사업보고서·2026 반기 후보 코드 `30399`와 달라 해당 기간을 제외했다. [별도](BROAD_303_VERIFIED_OFS_20261027.json)와 [연결](BROAD_303_VERIFIED_CFS_20261027.json) 스냅샷에 각각 **2개 법인·9개 기업기간 관측치**가 있다. [감사 결과](BROAD_303_VERIFIED_AUDIT_20261027.json)에 실행 ID, 제외 사유, 특성별 결측, 스냅샷 해시를 기록했다. 원문·기존 검증 배치·보고서·30392 스냅샷은 수정하지 않았다.

XBRL 자체 코드의 KSIC 개정 차수는 미확인이다. 따라서 이 스냅샷은 **탐색 후보**로 표시하고, ML의 `industry_revision` 게이트를 실패 처리한다. 각 범위의 기업 2곳·관측치 9개는 탐색적 비교 최소 10곳·20관측치에도 못 미친다. 실제 산업 비교 통계와 ML 모델은 생성하지 않았다. 추가 공식 자료와 실기업 원문 검증이 완료될 때마다 새 불변 스냅샷으로 재평가한다.

## 격리 DB에서 확장한 고정 표본

[고정 수집 계획](BROAD_303_COLLECTION_PLAN_20261027.json)은 신규 후보 24곳, 기준일 2026-10-27, 기업별 최대 60회 OpenDART 요청과 모델 0회를 명시한다. 운영 `session.db`에 신규 조사를 쌓지 않고 Git 제외 경로 `data/research/broad_303_20261027/`의 전용 DB·원문 저장소에서 실행했다. 실패 건도 포함한 전체 실행의 OpenDART 요청은 **996회**, 모델 호출은 **0회**다. 동일 후보에 대한 재시도는 별도 실행으로 남겼다.

24곳 중 **19곳**에서 네 가지 원문·기간·결산월·독립 XBRL 게이트를 통과한 분석용 관측치를 확보했다. 5곳은 결산월 확인 보류 1곳, 독립 XBRL 대응 실패 3곳, 접수번호와 격리 조사 연결 실패 1곳으로 제외했다. 이 제외는 회사 전체의 공시 부재나 재무 위험 판정이 아니다. 기존 2곳과 합친 [확장 감사](BROAD_303_EXPANDED_AUDIT_20261027.json)는 기업별 실행·제외 사유와 범위별 스냅샷 ID를 보존한다.

후속 재검증에서는 마지막 1곳(한국피아이엠)의 공시목록 접수번호 허용 검사 결함을 수정했다. 공식 사업보고서명과 보고기간을 확인한 경우에만 XBRL 요청을 허용했고, 재시도에서 OpenDART가 해당 XBRL 원본에 `014`(`file_not_found`)를 반환했다. 따라서 이 법인은 여전히 분석에서 제외한다. 해당 재시도 7회를 포함한 격리 DB 누적 요청은 **1,003회**다. 위 불변 확장 감사의 996회는 스냅샷 생성 시점 사용량이며, 스냅샷·통계·기존 감사 내용은 소급 변경하지 않았다.

- [별도재무제표 확장 스냅샷](BROAD_303_EXPANDED_OFS_20261027.json): 21개 법인, 86개 기업기간. 같은 기간·범위·통화·회계기준에서 `부채/자산 비율`의 2024-12-31·2025-06-30 기간별 각 20건, 총 탐색 비교 40건이 계산됐다. 다른 지표·기간은 표본 부족으로 보류됐다.
- [연결재무제표 확장 스냅샷](BROAD_303_EXPANDED_CFS_20261027.json): 20개 법인, 80개 기업기간. 개별 지표와 기간별 비교집단이 최소 표본 조건을 채우지 못해 비교 결과는 보류.

두 스냅샷 모두 XBRL에 관측된 `303` 계열 코드가 같은 법인·기간의 재무정보와 연결된 **탐색적 비교집단**이다. 코드가 실제 동일한 KSIC 개정 차수라는 공식 근거는 없고 세부 업종 코드도 서로 다르다. 정확한 `30392` 코호트와 수치를 합치지 않는다. 40건은 독립적인 40개 기업이나 검증된 산업 전체 효과를 뜻하지 않는다. 업종 개정 차수 게이트 때문에 충분한 다른 표본 조건과 무관하게 실제 ML 학습은 차단된다.

읽기 전용 API `GET /cohorts/broad-303/companies/{corp_code}/analysis?scope=OFS|CFS`는 감사 manifest의 스냅샷 ID·행 수와 파일 내용을 확인한 뒤 해당 법인의 통계 결과를 계산한다. 포함되지 않은 법인은 404, 무결성 실패는 503을 반환한다. 기존 조사 화면은 현재 법인이 이 스냅샷에 포함될 때만 탐색 비교를 표시한다. API와 화면 조회는 신규 OpenDART·모델 호출을 하지 않으며, 최신 공시 재검증이나 보고서 게시를 뜻하지 않는다.

## 재현

```sh
.venv/bin/python sh/build_broad_303_candidate_manifest.py
.venv/bin/python sh/build_broad_303_verified_snapshot.py
.venv/bin/python sh/plan_broad_303_collection.py
.venv/bin/python sh/collect_broad_303_batch.py --limit 24
.venv/bin/python sh/collect_broad_303_batch.py --limit 24 --retry-no-data
.venv/bin/python sh/evaluate_broad_303_expanded.py
.venv/bin/python -m unittest tests.test_broad_303_candidates tests.test_verified_run_peer
node sh/test_finance_analytics_ui.cjs
```

두 번째 명령에는 Git에서 제외한 현행 `session.db`와 보관 원문이 필요하다. 수집 명령에는 OpenDART 키와 실제 API 호출이 필요하며, 이미 완료된 후보는 진행 파일에 따라 건너뛴다. 확장 평가에는 격리 DB와 보관 원문도 필요하다. 이 파일이 없을 때 합성 수치로 대체하지 않는다. 게시 보고서나 PDF·ZIP은 만들지 않는다.

확장 평가 명령은 불변 파일을 덮어쓰지 않는다. 위 접수번호 후속 재시도 이후에는 격리 DB의 누적 API 사용량이 스냅샷 생성 당시와 달라졌다. 재실행 시 스냅샷 ID와 범위별 집계가 같으면 기존 감사를 보존하고 생성 당시·현재 요청 수를 따로 출력한다. 관측치가 실제 늘어나 스냅샷 ID가 바뀌면 새 버전이 필요하다는 오류로 중단한다.
