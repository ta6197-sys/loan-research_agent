# 비12월 결산 숫자 검증 및 KSIC 30392 자료 확보 후속

기준일: 2026-10-25. 기존 게시 보고서·검증 배치·코호트 스냅샷은 변경하지 않았다. 원문과 API 응답은 Git 제외 경로 `data/research/`에 보존하고, 이 문서 및 JSON 감사 파일에는 원문 해시와 판정만 기록한다.

## 1. 숫자 검증

`numeric-validation-1.30`은 기업코드가 맞는 공식 기업개황에서 결산월이 확인된 일반 기업의 연간·반기 기간을 계산한다. V04는 원문 표지의 당기 시작·종료일, API 조회 및 응답의 연도·보고서 코드, 재무제표별 당기·전기 열이 일치할 때만 통과한다. 기간·범위·통화·금액·원문 위치에 관한 나머지 필수 검사는 그대로 적용한다. 분기 보고서, 결산월 변경 이력 및 원문 기간이 모호한 경우에는 자동 통과시키지 않는다. OpenDART의 [단일회사 전체 재무제표 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020)에 명시된 보고서 코드와 금액 열의 의미를 사용했다.

실제 대조 대상은 6월 결산 세원정공(`00134316`)이다. 격리 저장소에서 OpenDART 공개 자료 외부 요청 22회로 원문 묶음 5개와 재무 API 요청 10회의 응답을 확보했다. 새 숫자 검증 배치 ID는 `869f774c6f57433ba5a8b11a0549eea8`다.

| 구분 | 결과 |
|---|---:|
| 원문 숫자 후보 | 447 |
| V04 기간 대응 통과 및 전체 필수 검사 통과 | 382 |
| API 계정 대응 부재·모호성으로 보류 | 65 |
| 숫자 후보의 V04 충돌 | 0 |
| V11 전기 비교 통과 | 63 |
| V11 전기 비교 보류 | 61 |

382건은 **확보한 원문 셀과 API 값의 규칙 기반 대조를 통과한 후보**다. 공시 자체의 진실성 또는 보고서 게시 가능성을 인증하지 않는다. 일반 기업 수집은 숫자 검증을 자동 실행하지 않으며, 비12월 보고서 컨텍스트·차트·분석·코호트 생성 게이트는 계속 닫혀 있다.

합성 시험에는 3월·6월·9월 결산의 연간/반기 열 매핑, 원문 표지 불일치 차단, 전기 비교 및 원문 위치 대조를 포함했다. 전체 회귀 `.venv/bin/python -m unittest discover -s tests -q`는 401건 통과했다.

## 2. 기존 30392 후보 자료 확보

기존 [117개 넓은 업종 후보](COHORT_DISCOVERY_20261025.md)의 OpenDART 기업개황을 기준일에 다시 조회했다. 117건 모두 응답을 얻었다. 결산월이 12월이 아닌 후보는 3곳이었다. 전체 프로필 응답 원문의 SHA-256은 [결산월 감사 JSON](COHORT_FISCAL_AUDIT_20261025.json)에 기록했다. 결산월과 넓은 업종코드는 5자리 KSIC 자체 분류나 금융 숫자 검증을 대신하지 않는다.

| 기업 | 결산월 | 2026 사업보고서 XBRL 자체 업종 | 조치 |
|---|---:|---|---|
| 동원모빌리티 | 03 | `452` | `30392` 근거 없음, 제외 |
| 세원정공 | 06 | `3031` | `30392` 근거 없음, 제외 |
| 덴소코리아 | 03 | 재무 API·공시목록 응답 `no_data` | 업종 자체 분류 미확인, 보류 |

각 후보의 조회 접수번호, API/XBRL 응답 및 XBRL 회원 파일 해시는 [비12월 후보 XBRL 감사 JSON](COHORT_FISCAL_XBRL_20261025.json)에 있다. 동원모빌리티·세원정공의 최신 자체 코드는 기존 기업개황의 넓은 `303`과 다르다. 자체 코드가 일치하지 않는 회사를 임의로 `30392`에 넣지 않는다. 덴소코리아의 `no_data`는 다른 업종이라는 증거가 아니다.

후보 프로필·XBRL 재조회 명령은 각각 `.venv/bin/python sh/audit_fiscal_cohort_candidates.py`, `.venv/bin/python sh/audit_fiscal_cohort_xbrl.py`다. 이미 보존한 원문은 재사용한다. 원문 파일은 Git 제외 경로에 저장된다.

현재 확보한 공식 원문으로 `30392` 자체 분류와 검증된 재무 관측치를 함께 충족하는 기업은 상신브레이크 1곳뿐이다. 따라서 기존 코호트 스냅샷은 유지하며 기업 간 통계와 실제 ML 학습은 계속 보류한다. 추가 확보에는 `30392` 법인별 공식 세세분류 목록 또는 해당 분류가 명시된 기업 자체 공시와 법인코드가 필요하다. 이후에도 각 기업의 원문·API 숫자 대조, 회계기준 및 공개 시점 확인을 통과해야 한다.
