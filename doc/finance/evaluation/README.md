# 검증용 기대 결과 자료 — 1단계

작성일:2026-10-21. 사용자는 Markdown+JSON, 문장 일치 대신 의미/근거 평가, 가상 후속 자료 별도 작성을 선택했다.

## 읽는 순서

- [기대 결과표](EXPECTED_RESULTS.md): 사람이 검토할13개 행동 기준, 별도 수치표·금지 해석·질문.
- [비교용 JSON](expected_results.json):13개 계정×5기간×2범위의130개 정확값·원문/API 위치,30개 산술,13개 행동 기준,7개 오류 상황.
- [원문 확인 기록](REFERENCE_VERIFICATION.json): 이번 자료 준비에서 실제 확인한 범위. 제품 시험 결과가 아님.
- [원문 해시 목록](source_manifest.json): 변경을 감지할 고정 원문 목록. 경로 기준은 프로젝트 최상위.
- [가상 후속 시험](synthetic/README.md): 실제 기업과 분리한3개 후속 시나리오·TXT 입력·기대 갱신.

## 사용 원칙

현재 단계는 **기준 자료 준비**다. 보고서 생성·의미 채점·고정 절차와 에이전트 각3회 비교는 아직 하지 않았다. expected_results의status와 실제 실행 점수를 혼동하지 않는다. 정당한 보류와 공개 항목 누락을 분리하며, 의미 채점을 키워드 존재 검사로 대체하지 않는다.

기준을 비교할 때 제품 출력에 근거 ID·원시 숫자·단위·기간·별도/연결·계산·검증 상태가 남아야 한다. 문장을 그대로 복사했는지는 평가하지 않는다. 기준 밖의 해석이라도 실제 근거가 지원하는지 별도로 검토하고 기준표를 코드 출력에 맞춰 자동 변경하지 않는다.

실제 공시 원문 대조는 에이전트의 수행 책임으로 정한 기존 설계를 따른다. 이 자료는 은행 전문가나 독립 평가자의 검증을 확보했다는 뜻이 아니다. NCS 원문·도표·서식은 사용하지 않았다.
