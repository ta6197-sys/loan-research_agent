# 가상 후속 입력 시험 — 실제 기업 자료 아님

이 폴더의 숫자·회사·답변은 직접 만든 시험 데이터다. 상신브레이크나 실제 IBK 고객의 자료가 아니다. 기존 실제 공시 기준표와 별도 조사/시험 공간에서만 사용한다.

1. `public_context.json`의 검증용 가상 제조기업 A를 별도 시험 문맥으로 준비한다. 실제 DART 자료로 표시하지 않는다.
2. S01·S02·S03은 독립 시나리오다. 각 시나리오는 같은 초기 가상 문맥에서 시작한다. 앞 시나리오의 답변을 다음 시나리오에 자동 누적하지 않는다.
3. 각 TXT를 첨부 포함 메시지로 전송해 후속 입력을 시험한다. 별도 조사 시작 버튼을 요구하지 않는다.
4. `followup_cases.json`의 expected_changes·must_not·expected_run_behavior를 실제 출력/이력과 대조한다. 아직 시험을 실행한 결과가 아니다.

| 시나리오 | 확인할 것 |
| --- | --- |
| S01 회수 일부 확인 | 실제 회수와 예정의 구분, 나머지 실제 회수 확인 질문, 기존 기준일 잔액 보존 |
| S02 용도·조건 추가 | 사용자 제공 조건으로 표시, 상환 자료 미제공 질문 유지, 승인/한도 결정 금지 |
| S03 숫자 충돌 | 사용자 설명으로 기준 숫자를 덮어쓰지 않고 근거·기간·범위/정정 확인 |

가상 자료로 원문 대조가 잘 됐다고 주장하거나 실제 기업의 내부 회수 정보가 확인됐다고 소개하지 않는다. 프로그램 검증용 가상 문맥을 자동 등록하는 기능은 구현하지 않았다.
