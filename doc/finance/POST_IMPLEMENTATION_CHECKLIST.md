# 구현 완료 후 재확인 체크리스트

이 목록은 기능 구현이 끝난 뒤 시연·배포·일반 기업 확대 전에 다시 확인할 항목입니다. 체크 완료가 대출 승인 판단이나 금융 자료 전체 확인을 의미하지 않습니다.

## 1. 코드와 재현성

- [ ] 깨끗한 가상환경에서 의존성을 설치하고 서버·화면이 정상 기동하는지 확인한다.
- [ ] 전체 자동 시험과 단계별 검증 명령이 통과하는지 확인한다.
- [ ] 실행에 사용한 Python, Node, 모델, 라이브러리 버전과 커밋 ID를 기록한다.
- [ ] 템플릿 변경 뒤 `node sh/build_finance_ui.cjs`를 실행하고 화면에 반영됐는지 확인한다.
- [ ] 배포 ZIP을 새 경로에 만들고 설치·실행 가능한지 확인한다.

## 2. 보관 사례와 금융 근거

- [ ] 상신브레이크 보관 사례의 확인 114건과 보류 16건이 재시작 후에도 동일하게 표시되는지 확인한다.
- [ ] 보류 항목이 숫자 0, 확인 사실, 또는 추정치로 바뀌지 않았는지 확인한다.
- [ ] 각 게시 수치가 법인·기간·별도/연결·단위·계정·원문 위치를 함께 가리키는지 표본 대조한다.
- [ ] XBRL 차입 연결에서 본문의 대시·빈칸이 명시적 0으로 바뀌지 않았는지 확인한다.
- [ ] 은행 표기가 다른 차입 상세 항목은 구성요소가 모두 일치할 때만 연결되는지 확인한다.
- [ ] 원문 해시와 근거 바이트 위치가 보존됐는지, 원문이나 기존 검증 이력이 변경되지 않았는지 확인한다.

## 3. 보고서와 사용자 흐름

- [ ] 새 조사, 저장된 조사 열기, 근거 열람, 질문·답변, 정정, 버전 비교가 화면에서 동작하는지 확인한다.
- [ ] 답변·정정 후 이전 판은 그대로 남고 새 판만 게시되는지 확인한다.
- [ ] 질문·정정·메모가 검증 전 사실로 표시되지 않는지 확인한다.
- [ ] PDF와 Markdown ZIP에 선택한 판의 근거·미확인 표기가 유지되는지 확인한다.
- [ ] 브라우저 새로고침과 서버 재시작 뒤에도 조사 상태·이력·보류 상태가 동일한지 확인한다.
- [ ] 중단·재개·장애 복구 시 중복 실행이나 예산 중복 차감이 없는지 확인한다.

## 4. 외부 모델과 키

- [ ] 기본 실행이 로컬 모델을 유지하고, 키 존재만으로 OpenAI로 전환되지 않는지 확인한다.
- [ ] OpenAI 실행 시 명시 동의·원문별 전송 정책·사용량 상한이 적용되는지 확인한다.
- [ ] 승인된 공개 공시 근거만 전송하며 원문 파일·사용자 답변·첨부·DB 경로·키가 제외되는지 확인한다.
- [ ] 모델 출력이 검증을 통과하지 못하면 게시되지 않고 보류되는지 확인한다.
- [ ] `.env.openai.local`, DB, 원문, 키가 Git 상태와 배포 ZIP에 포함되지 않는지 확인한다.

## 5. 일반 기업 자동 수집 전 추가 확인

- [ ] OpenDART 키의 사용 권한, 대상 기업, 공시 기준일, 최대 요청 수를 확정한다.
- [ ] 해당 회사 자료의 이용 조건과 외부 모델 전송 허용 범위를 자료별로 확인한다.
- [ ] 실제 호출 전 요청 수·재시도·용량 한도와 중단 기준을 기록한다.
- [ ] 수집 결과를 기존 보관 사례와 분리한 분석 저장소에 저장한다.
- [ ] 한 기업·한 기준일로 파일 구조, XBRL 계정 대응, 원문 인용, 보류 처리를 먼저 검증한다.
- [ ] 신규 수집 결과를 전체 금융 확인 완료나 일반화된 정확성으로 표시하지 않는다.

## 6. 보안과 운영 전환

- [ ] 서버가 루프백 주소에서만 열리고 Host/Origin 검사가 유지되는지 확인한다.
- [ ] 허용목록 밖 도구, 외부 URL, 리다이렉트, 인증 이동 주소가 거부·기록 최소화되는지 확인한다.
- [ ] 로그와 화면에 API 키·인증 URL·원문 경로·개인 정보가 노출되지 않는지 점검한다.
- [ ] 백업·복원 절차를 실제 복사본에서 연습하고, 원본 DB와 원문을 삭제하지 않는지 확인한다.
- [ ] 다중 사용자, 저장 암호화, 위변조 방지 감사 로그, 인터넷 공개 운영은 별도 설계·검증 전까지 한계로 표시한다.

## 7. 평가와 인수 확인

- [ ] 보관 사례와 합성 실패 사례를 같은 모델·자료·예산으로 재실행한다.
- [ ] 고정 절차와 에이전트의 비교 결과, 실패 원인, 재현 조건을 함께 보존한다.
- [ ] 정확도·누락 감소·시간 절감은 측정 근거가 있을 때만 주장한다.
- [ ] 실제 금융 전문가가 검토하지 않은 결론은 전문가 검토 완료로 표시하지 않는다.
- [ ] 시연 대상자가 확인할 화면·입력·출력·한계 문구를 인수 기준으로 합의한다.
