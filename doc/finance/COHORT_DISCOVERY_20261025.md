# KSIC 30392 비교기업 후보 후속 조사

조사일: 2026-10-25. 이 문서는 **후보 탐색** 기록이다. 기업개황 코드나 XBRL 자체 분류만으로 검증된 재무 관측치 또는 ML 학습 행을 만들지 않는다. 정규화한 117개 후보와 접수번호는 [후보 점검 JSON](COHORT_CANDIDATE_AUDIT_20261025.json)에 기록했다.

## 범위와 방법

1. 2026-10-22에 저장된 OpenDART 법인 목록의 주식코드가 비어 있지 않은 법인 4,000곳을 사용했다. 이 조건은 현재 상장 상태 확인과 다르다. 2026-10-23에 조회한 3,159곳에 이어 2026-10-25에 841곳의 [기업개황](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002)을 조회했다. 서로 다른 4,000곳 모두 정상 응답이었다.
2. `induty_code=30` 또는 `303`으로 시작하는 117곳을 넓게 선별했다. `303` 정확히 91곳, `30` 7곳, 그 밖의 `303` 하위 코드 19곳이다. 기업개황에서 `30392`를 직접 표기한 곳은 없었다.
3. 117곳의 2025 사업보고서와 2026 반기보고서 접수번호를 재무 API에서 찾고, 확보한 접수번호의 [XBRL 원본](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS002&apiId=2019019)에서 법인 자체 `StandardIndustryCode`를 확인했다. 재무 API에 접수번호가 없는 후보는 [공시검색](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001)으로 다시 확인했다. 이 탐색은 원문 수치 검증과 별개다.

| 단계 | 확인 결과 |
|---|---|
| 기업개황 | 4,000/4,000 정상 응답. `30392` 직접 표기 0곳 |
| 넓은 업종 후보 | 117곳 (`303` 91, `30` 7, 다른 `303*` 19) |
| 2025 사업보고서 XBRL | 102곳에서 3~5자리 코드를 읽음. 4곳은 코드 미추출, 11곳은 재무 API 접수번호 없음 |
| 2026 반기 XBRL | 100곳에서 3~5자리 코드를 읽음. 4곳은 `30` 또는 `45`의 2자리 코드, 13곳은 재무 API 접수번호 없음 |
| `30392` 자체 분류 | 두 보고기간에서 상신브레이크 1곳만 확인 |

2026 반기 XBRL에서 2자리 코드만 나온 4곳은 피에이치에이 `30`, 씨티알모빌리티 `30`, 삼기 `45`, 서진오토모티브 `30`이다. 이 값으로 세세분류 `30392`를 추정하지 않는다. 재무 API 접수번호를 얻지 못한 곳 중 일부는 공시목록에 보고서가 있었지만 XBRL 원본 API가 `file_not_found`를 반환했다. 다른 일부는 해당 검색창에서 정기 공시를 찾지 못했다. 자세한 상태와 접수번호는 후보 점검 JSON에 분리해 남겼다.

## 코호트 판단과 한계

상신브레이크의 2025 사업보고서 접수번호는 `20260318001187`, 2026 반기보고서는 `20260813000874`이며 두 XBRL 모두 `30392`다. 다른 후보에서는 확인 가능한 2025 사업보고서 또는 2026 반기 XBRL에서 `30392`를 읽지 못했다. 공시·XBRL이 없거나 분류가 넓은 법인에 대해서는 다른 세세분류라고 확정하지 않는다.

이번 후속 조회는 2026-10-23 기준으로 저장된 [기존 검증 코호트](COHORT_DISCOVERY_20261023.md)에 기업을 추가하지 않았다. 신규 기업이 확인되더라도 해당 기준일에 공개된 자체 산업 근거, 회계기준, 원문 수치·검증 배치와 게시 보고서를 별도로 확보한 뒤 새로운 불변 스냅샷을 만들어야 한다. 현재 비교 가능한 검증 기업은 상신브레이크 1곳·기간 관측치 5개이며, 기업 간 통계와 ML 학습은 계속 보류한다.

이번 탐색의 응답 요약과 XBRL 파일은 분석 저장소의 `research_sources`에 등록하지 않았다. 후보 점검 JSON은 재조회 계획과 제외 사유 추적용이며 원문 근거 또는 검증 완료 데이터셋이 아니다. 대상 범위도 2026-10-22 법인 목록에서 주식코드가 있는 법인으로 제한되어, 주식코드가 없는 회사나 목록 갱신 후 추가된 법인 전체에 대한 부재 증명은 아니다.
