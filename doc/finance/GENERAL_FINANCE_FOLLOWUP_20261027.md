# 로컬 모델·범용 기업 재현·광역 303 결측 후속 감사

기준일 2026-10-27. 게시 보고서, 기존 검증 배치와 코호트 스냅샷은 변경하지 않았다.

## 1. 로컬 모델 확인

실행 중인 금융 서버의 `/health` 응답은 `finance_model_backend=ollama`였다. 설치된 모델은 `qwen3.5:2b`다. 이전 합성 평가의 20회 한도는 그대로 보존하고, 사용자가 승인한 별도 `20261027` 회차를 최대 5회로 고정했다. 합성 근거 3건은 3회 호출로 모두 통과했다. 이어 현대공업의 기존 검증 수치 두 문장과 보류 항목 하나를 로컬 모델에 전달해 1회 호출로 근거 원문 복사, 보류 ID 보존, 후속 질문 생성을 확인했다. 원격 모델 호출과 보고서 생성은 없었다. [결과 계약](LOCAL_MODEL_VERIFICATION_20261027.json)에 실행 횟수·검증 ID·원문 ID·한계를 기록했다.

이 검사는 작은 입력의 생성 계약이다. 재무 수치 자체의 검증은 기존 원문/API·기간·결산월·XBRL 게이트에 의존하며, 모델 응답만으로 새 금융 사실을 만들지 않는다.

## 2. 현대공업 범용 조사 읽기 재현

기존 격리 DB에서 현대공업(`00164502`)의 정기공시 조사 실행을 읽기 전용으로 재현했다. `GET /runs/{run_id}/verified-analysis`를 같은 저장소에 연결한 인프로세스 API 호출로 확인했다. 수치 89행 확인·41행 보류, 독립 XBRL 및 정정 이력 통과, 분석용 기업기간 10개가 기존 감사와 일치했다. 분석 근거가 가리키는 보관 원문 5개의 SHA-256을 재계산했고, 별도·연결 스냅샷의 해당 기업 행도 재계산 결과와 일치했다. [재현 결과](GENERAL_COMPANY_REPLAY_HYUNDAI_20261027.json)에 실행·배치·해시 식별자를 기록했다.

이 재현은 새 공시 기준일의 수집 성공이나 로컬 모델을 사용한 실제 보고서 게시를 의미하지 않는다. 외부 API와 모델 호출은 0회였다.

## 3. 광역 303 지표 결측 원인

[결측 감사](BROAD_303_FEATURE_GAP_AUDIT_20261027.json)는 확장 스냅샷의 별도 86·연결 80개 기업기간을 대상으로 검증 상태와 분석 결과의 대표 보류 사유를 연결한다.

현재 실제 탐색 비교 40건은 별도 부채/자산 지표의 2024년 말·2025년 반기에 한정된다. 연결의 같은 두 기간은 각각 19개 법인으로 최소 20곳에 한 곳 부족하다. 보류 값을 0이나 추정치로 채우지 않으며, 업종 개정 차수 미확인으로 ML 학습은 계속 차단한다.

## 4. 고정 한도 증분 수집과 v2 비교

[증분 계획](BROAD_303_INCREMENT_PLAN_20261027.json)의 12개 기업만 별도 격리 DB에서 조사했다. 기업별 최대 60회, 전체 최대 720회로 고정했고 실제 OpenDART 요청은 570회, 모델 호출은 0회였다. 9곳은 원문/API 값, 기간, 결산월, 독립 XBRL 검증을 통과해 분석용 스냅샷에 추가됐다. 우리산업은 정정 원본 관계를 확인하지 못해 보류했고, 케이엔더블유·삼기에너지솔루션즈는 기업별 요청 한도 내에서 검증을 완료하지 못해 제외했다. 보류 기업의 숫자는 분석에 포함하지 않았다.

[v2 감사](BROAD_303_EXPANDED_V2_AUDIT_20261027.json)와 별도 [v2 OFS](BROAD_303_EXPANDED_V2_OFS_20261027.json)·[v2 CFS](BROAD_303_EXPANDED_V2_CFS_20261027.json) 스냅샷은 기존 v1 파일과 검증 배치를 수정하지 않는다. OFS는 30개 법인·123개 기업기간에서 탐색 비교 192건, CFS는 29개 법인·117개 기업기간에서 257건이다. 화면과 API의 기본값은 v2이며 `snapshot_version=v1`로 이전 결과를 재현할 수 있다. 이 수는 통계적 신뢰도나 신용위험 판정을 뜻하지 않는다.

[v2 결측 감사](BROAD_303_FEATURE_GAP_AUDIT_V2_20261027.json)에서 부채/자산 비율은 OFS 120/123, CFS 112/117, 영업이익률은 OFS 68/123, CFS 87/117이다. 매출 증가율은 OFS 1/123, CFS 0/117로 비교기간·검증 계정 대응이 여전히 병목이다. 차입금/자산은 후보 특성의 계산 정책이 아직 확정되지 않았고, 기존 자료에서 세 차입 구성 계정이 동일 기간에 모두 검증된 사례도 없으므로 값을 만들지 않았다. 업종 개정 차수가 미확인인 상태라 v2에서도 ML은 `not_trained_insufficient_data`다.

## 5. 후속 V12 차입금/자산 정책

사용자가 승인한 엄격한 V12 조건을 `verified-financial-features-1.1`로 구현했다. 새 분석에서는 같은 법인·범위·시점의 단기차입금, 유동성장기차입금, 장기차입금 세 행이 모두 원문 및 필수 수치 검증을 통과하고, 각 행의 V12 구성 검사가 `pass`이며, 검증된 자산 분모가 양수일 때만 Decimal로 비율을 계산한다. 입력 사실·검증·원문 ID를 결과에 붙인다. 조건이 부족하면 `unmeasured` 또는 `withheld`와 사유를 반환한다. 기존 v1·v2 스냅샷과 감사의 수치는 소급 변경하지 않는다. 보관된 v2 관측치에는 세 계정이 모두 확인된 동일 기간이 없어 새 비율 값은 아직 0건이다.
