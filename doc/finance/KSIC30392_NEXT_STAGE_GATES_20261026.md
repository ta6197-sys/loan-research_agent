# 30392 후보·비12월 결산 후속 게이트

기준일: 2026-10-26. 이 문서는 [공식 출처 감사](KSIC30392_OFFICIAL_SOURCE_AUDIT.md) 뒤에 적용한 실행 기준과 결과다. 기존 공시 원문·검증 배치·게시 보고서·코호트 스냅샷은 수정하지 않았다.

## 1. 법인 식별 상태

`candidate_identity.py`는 공장 후보를 `확인`, `충돌`, `미확인`으로 기록한다. `확인`에는 법인 고유번호, 법인 주소, 공장 소재지, 공식 등록 근거, 법인 업종 및 KSIC 차수의 각 독립 대조가 모두 `pass`이고 공식 출처 URL·SHA-256·대응값이 남아야 한다. 회사명 일치나 가능한 DART 코드만으로는 다음 단계에 넘기지 않는다.

[공장 후보 판정 JSON](KSIC30392_IDENTITY_TRIAGE_20261026.json)에서 43건은 `미확인` 42건, `충돌` 1건, `확인` 0건이다. 팩토리온 2021년 파일에는 상세 주소와 공장등록번호가 없으며, 고양시 파일의 소재지만으로 법인 등록 주소·동일 법인을 확인할 수 없다. 1건의 `충돌`은 한국토미의 **공장 업종 30392와 가능한 DART 법인 기업개황 업종 3020의 불일치**를 뜻한다. 두 사업체가 법적으로 동일하다는 확정 판정은 아니다. 사용자는 현재 추가 공식 등록부·식별자 자료를 제공할 수 없다고 답했으므로 `확인`으로 승격하지 않는다.

## 2. KSIC 개정 차수와 수집 계획

공장 원본의 SHA-256과 행 번호, 제9·10·11차 버전, 출처 날짜·URL을 후보 판정에 연결했다. 공식 개정 차수 대응표는 확보되지 않아 `ksic_correspondence_source=null`로 명시했고 버전을 합치지 않았다. DART 13곳도 30392 값은 확인했지만 화면의 개정 차수는 미표시이며, 조회 범위의 사업·반기보고서는 0건이다.

상세 공시 수집 전에 기준일 `2026-10-26`, 법인 대상 목록 `[]`, 최대 요청 수 `0`, 회사당 최대 보고서 `2`를 [판정 JSON](KSIC30392_IDENTITY_TRIAGE_20261026.json)의 `collection_plan`에 고정했다. 공시가 없는 기업은 `비상장 또는 공시 미확인`으로 기록하며 재무 결측값은 `null`이다. 새로운 대량 조회는 하지 않았다. 향후 `확인` 법인과 정기공시가 나타나면 **새 기준일·요청 한도의 별도 계획**을 작성한 뒤 수집한다.

## 3. 분석 행과 불변 스냅샷

새 실제 공개자료 행은 원문/API 일치, 실제 보고기간, 결산월, 독립 XBRL 계정·기간·금액의 네 게이트를 모두 통과해야 한다. 새 일반 기업의 12월·비12월 보고서 게시 게이트에도 독립 XBRL을 요구한다. `verified_peer_builder.py`가 게시 행과 배치를 다시 대조하고, `peer_dataset.py`가 각 행의 게이트 상태를 재검사한다. 빠진 게이트의 값은 특성·통계·ML 입력이 될 수 없다. 합성 시험 자료는 `synthetic_test_only`로 구분한다.

새 코호트 스냅샷의 manifest에는 포함 기업·보고서·원문 해시·검증 배치·네 게이트, 제외 사유, KSIC 정책·근거, 공개 기준일을 넣고 기존 불변 테이블에 새 레코드로 저장한다. 기존 스냅샷과 보고서는 갱신하지 않는다. 업종 개정 차수가 다르면 `cohort_registry.py`의 기존 KSIC 11 정책에 따라 한 코호트에 혼합하지 않는다.

## 4. 세원정공 별도 출력 회귀

세원정공은 **30392 코호트 후보가 아닌 6월 결산 검증 사례**다. 기존 검증 저장소의 격리 사본에서 보고서 1판을 게시하고 UI 읽기 모델과 PDF·ZIP을 생성했다. [출력 감사 JSON](SEWON_OUTPUT_REGRESSION_20261026.json)에 원본 사본 DB 해시, 출력 해시, 보고서 ID와 뷰 해시를 기록했다. 게시 수치 86행·보류 44행, 차트 `available_with_gaps` 2개·`withheld` 2개, PDF 16쪽, ZIP 차트 2개다. 회사명·공개 기준일 `2026-10-25`·1판·미확인 표시를 서로 대조했다. 보류 차트의 근거가 확보되지 않아 활성화하지 않았다. 로컬 모델 설명은 사용하지 못한 상태로 표시했고 검증 수치와 미확인 질문만 출력했다. 실제 사용자 보고서나 원본 자료를 게시·수정한 결과가 아니다.

## 5. 데이터 회귀와 출력 회귀

데이터 회귀: 원문 해시·위치, 회사·범위·기간 일치, V 규칙, 독립 XBRL, 결산월, 기존 스냅샷 불변성, 누락 수치와 0의 구분을 검사한다. 출력 회귀: 읽기 모델과 PDF·ZIP의 기업명·기준일·보고서 판·보류 상태·차트 포함 여부를 검사한다. `sh/verify_fiscal_report_gate.py`와 `sh/verify_sewon_output_regression.py`는 각각 격리된 데이터·출력 재현을 수행한다.

## 6. 통계·ML 재평가

새로 편입된 30392 법인·기간은 0이다. 기존 30392 코호트는 상신브레이크 1곳·5기간이며 통계·ML 게이트는 계속 미달이다. 모델의 라벨 품질 항목은 IsolationForest가 비지도 탐색 모델임을 `not_applicable_unsupervised`로 명시하고 실제 운영 정확도를 산출하지 않는다. 합성 자료의 탐지 결과에는 실제 기업 성능이 아니라는 한계를 표시한다.
